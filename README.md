# Conversor de Moedas Simples

Este projeto é uma versão simples de conversor de moedas em HTML, CSS e JavaScript.

## Arquivos

- `index.html` — estrutura da página
- `styles.css` — estilos
- `script.js` — lógica da conversão

## Como executar

Abra o arquivo `index.html` em um navegador.

## Funcionalidades

- Conversão entre diferentes moedas
- Campo para inserir valor
- Troca de moedas
- Cálculo instantâneo
